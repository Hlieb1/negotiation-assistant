# Android-застосунок

Код: `android/` (Kotlin, Jetpack Compose, CameraX, AudioRecord, OkHttp).

## Що робить застосунок

| Модуль | Файл | Що робить |
|---|---|---|
| Запис відео | `capture/FrameAnalyzer.kt` | CameraX ImageAnalysis (≈640×480, RGBA), стиснення в JPEG (якість 80) з урахуванням повороту; на сервер надсилається 3–5 кадрів/с (налаштовується) |
| Запис аудіо | `capture/AudioStreamer.kt` | AudioRecord, 16 кГц, моно, PCM 16 біт, фрагменти по 2 с; джерело `VOICE_RECOGNITION` (без автоматичного регулювання гучності, щоб не спотворювати ознаки голосу) |
| Мережевий клієнт | `net/NegotiationClient.kt`, `net/Protocol.kt` | WebSocket (OkHttp), ping кожні 10 с, автоматичне перепідключення із затримкою 1, 2, 4, 8 с; після перепідключення сесія відновлюється сама. Якщо мережа не встигає, кадри відкидаються (черга > 512 КБ) |
| Керування сесією | `ui/SessionViewModel.kt` | старт/стоп, режим А/Б/гібрид, лічильники надісланих даних, обробка повідомлень сервера |
| Відображення підказок | `ui/SessionScreen.kt` | прев'ю камери, стан співрозмовника кольором, смуга впевненості, велика репліка, тон, затримка |
| Налаштування | `ui/SettingsScreen.kt`, `data/SettingsStore.kt` | IP і порт сервера, режим, камера (основна/фронтальна), кадрів/с; зберігаються в DataStore |

**Етичні вимоги.** Перед кожним стартом з'являється вікно з поясненням, що застосунок аналізує обличчя й голос. Сесію можна почати лише після позначки «Співрозмовника попереджено, згоду отримано». Під час аналізу на екрані горить червоний індикатор «Аналіз». Відео і звук не зберігаються ні на телефоні, ні (за замовчуванням) на сервері.

## 1. Підготовка ноутбука

1. Запустіть сервер:
   ```
   cd D:\Diploma\server
   .venv\Scripts\python.exe -m app
   ```
   Дочекайтеся рядка `models ready` (~1–1,5 хв).
2. Дізнайтеся IP ноутбука в мережі Wi-Fi:
   ```
   ipconfig
   ```
   Потрібна «IPv4-адреса» адаптера Wi-Fi (наприклад, `192.168.68.122`).
3. Дозвольте вхідні з'єднання на порт 8000. Мережа Wi-Fi має бути **приватною**: Параметри → Мережа та Інтернет → Wi-Fi → ваша мережа → «Приватна мережа». Потім у PowerShell **від імені адміністратора**:
   ```
   netsh advfirewall firewall add rule name="Negotiation assistant 8000" dir=in action=allow protocol=TCP localport=8000 profile=private
   ```
4. Перевірка з телефона: у браузері телефона відкрийте `http://<IP ноутбука>:8000/health` — має з'явитися `{"status":"ok"}`.

## 2. Збірка APK

Через Android Studio: File → Open → `D:\Diploma\android`, дочекатися синхронізації Gradle, Build → Build App Bundle(s) / APK(s) → Build APK(s).

Або з командного рядка (потрібен JDK 17 або 21; Android Studio має його в `jbr`, або Gradle сам знайде JDK 21 завдяки `gradle/gradle-daemon-jvm.properties`):
```
cd D:\Diploma\android
.\gradlew.bat assembleDebug
```
Готовий файл: `android\app\build\outputs\apk\debug\app-debug.apk`.

## 3. Встановлення на телефон

**Варіант А — кабель USB (adb):**
1. На телефоні: Налаштування → Про телефон → 7 разів торкнутися «Номер збірки» (з'явиться режим розробника).
2. Налаштування → Для розробників → увімкнути «Налагодження USB».
3. Підключити телефон кабелем, на телефоні дозволити налагодження для цього комп'ютера.
4. На ноутбуці:
   ```
   %LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe install -r D:\Diploma\android\app\build\outputs\apk\debug\app-debug.apk
   ```

**Варіант Б — без кабелю:** скопіюйте `app-debug.apk` на телефон (Telegram «Збережене», Google Drive тощо), відкрийте файл на телефоні й дозвольте встановлення з цього джерела.

## 4. Робота

1. Відкрийте «Переговорний асистент» → введіть IP ноутбука, порт 8000, оберіть режим (А, Б або гібрид) і камеру → «Зберегти і перейти до сесії».
2. Дозвольте доступ до камери й мікрофона.
3. Поставте телефон на стіл основною камерою на співрозмовника.
4. «Старт» → підтвердіть, що співрозмовника попереджено → «Почати».
5. Угорі має бути «підключено», нижче — лічильники надісланих кадрів і аудіо. Підказка з'являється, коли змінюється стан співрозмовника (не частіше ніж раз на 4 с).
6. «Стоп» завершує сесію. Журнал сесії — у `server\logs\<дата_час>.jsonl`.

## 5. Якщо не підключається

| Ознака | Що перевірити |
|---|---|
| «перепідключення…» постійно | сервер запущено? IP правильний? `http://IP:8000/health` відкривається в браузері телефона? |
| `/health` не відкривається з телефона, але відкривається на ноутбуці | брандмауер (крок 1.3), профіль мережі «Приватна», телефон і ноутбук в одній мережі (не гостьова Wi-Fi з ізоляцією клієнтів) |
| Підказок немає, лічильники ростуть | обличчя має бути в кадрі; підказка надходить лише при зміні стану |
| Лічильник аудіо не росте | дозвіл мікрофона; інший застосунок не займає мікрофон |
